# /learn - Extract Reusable Grant-Writing Patterns

Analyze the current session and extract any patterns worth saving as a learned skill — see the `continuous-learning` skill for the full pattern types and format.

## Trigger

Run `/learn` at any point during a session when a funder preference, voice correction, or reviewer-feedback pattern came up that's worth remembering next time.

## What to Extract

1. **Funder Preferences** — what a specific funder values, avoids, or requires
2. **Voice Corrections** — edits made to bring a draft in line with GOODProjects house style
3. **Successful Framing** — an argument or angle the user confirmed worked
4. **Reviewer Feedback Patterns** — recurring notes from human review
5. **Process Workarounds** — repo/tooling quirks discovered while drafting

## Process

1. Review the session for extractable patterns.
2. Check it isn't redundant with `gp-grant-writer`'s existing canon — funder-specific facts usually belong there, not as a standalone learned skill.
3. Draft the skill file per the format in `continuous-learning/SKILL.md`.
4. **Ask the user to confirm before saving.**
5. Save to `.claude/skills/learned/[pattern-name]/SKILL.md`.

## Notes

- Don't extract trivial or one-time issues.
- Focus on patterns that will save time on a future draft to the same funder or in the same voice.
- Keep each learned skill focused — one pattern per file.
